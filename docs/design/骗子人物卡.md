# 骗子人物卡与剧本补充（D34）

拍板：Dylan，2026-11-11。

## 为什么要做

- 现在的骗子方只有剧本里一句 `persona` 和每个阶段的示例台词。它不会怀疑、不会试探，也记不住自己编过的细节。
- 诱饵（D32）的第一条原则是「不被发现是 AI」。如果对手从来不起疑，这条原则就测不出来。
- 骗子起疑以后，可能发假地址或别人的地址，这正是 D33 要防的情况。现在没有对手会真的这么做，D33 也就测不到。
- 现在有 36 个剧本、10 类骗局，英文只有 11 个。常见的冒充公检法、跑分洗钱、假挖矿授权这三类还没有。

## 两层人物（同 RPG：写事实，不写形容词）

| 层 | 是什么 | 放在哪 |
|---|---|---|
| **面具** `ScriptCover` | 骗子对受害者自称的身份：名字、年龄、职业、所在地、身世、提到的人、能拿出来的「道具」（截图、群名、工牌）、不能视频的理由 | 每个剧本的 `cover` 字段，和这个剧本的 `persona` 一致 |
| **真人** `ScammerCard` | 键盘后面真正打字的人：在哪种园区或窝点、班次、业绩压力、照不照话术念、会露哪些马脚、什么情况会怀疑对方是诱饵或 AI 或警察、怎么试探、起疑后怎么做、底线 | `fixtures/scammers/{zh,en}.json`，中英各 3 张，按骗局类型选（同诱饵：session id 哈希，同一局固定） |

真人卡是根据公开报道拼出来的虚构人物，不对应任何真实的人。

## 骗子每轮怎么想（AI 扮骗子时）

输出一个 JSON：

```json
{"think":"≤80字","bait_suspicion":{"score":0-100,"signals":["问得太细","秒回","说话像客服"]},"plan":"接下来2-3轮","action":null,"new_facts":["我说过姑姑在新加坡"],"reply":"真正发出去的话"}
```

`action` 可以是 `"test"`、`"poison"`、`"vanish"`，或者 `null`。

- **怀疑度**取滑动平均，存进 `ScammerMind.baitSuspicion`。
- **新事实**写进账本，以后每轮都给模型看，保证面具前后一致。
- **起疑后的行为**（只在 `real` 模式下生效）：
  - **≥ 60**：从真人卡的 `tests` 里挑一个来试探，比如让对方发带今天日期的自拍、发语音，或者问一个陷阱问题。记为 `test`。
  - **≥ 80**，并且到了要给收款地址的阶段：
    - 剧本有 `poison` 的，改给投毒地址，记为 `poison`。D33 应该拦下这个地址或者挂警告。
    - 剧本没有 `poison` 的，就拖着不给地址，并且再试探一次。
  - **连续两轮 ≥ 90**：发一句收尾的话，然后消失，记为 `vanish`，这一局结束。
- **easy 模式**：只记录怀疑度，行为和现在一样，到了阶段照样给地址。
- **安全规则不变**：骗子只能用剧本里的虚构地址、网址和号码，绝不编真的。

规则引擎（不调模型）也要有怀疑度：
- 诱饵说出 AI 腔，或者 `aiTells` 命中、主动提到警察或报警、一轮里问 3 个以上的问题，都加分；
- 正常闲聊或跑题说自己的事，减分。
- 加减多少，要能被测试固定住。

## 模式

- 新建对局时可以带可选参数 `scammerMode: "easy" | "real"`。网页和 IM 默认用 `real`，因为专家训练要面对真实的对手。
- 评测默认用 `easy`，保证回归结果稳定；加 `--real` 跑对抗版。

## 评测

| 指标 | 怎么算 |
|---|---|
| `baitSuspicion` | 结束时骗子对诱饵的怀疑度（越低说明诱饵越像真人） |
| `scammerVanished` | 拿到地址之前骗子就跑了 |
| 汇总 `avgBaitSuspicion`、`vanished` | 同上 |

## 可见范围

- 真人卡、面具、骗子心智和每轮的 `scammerMind`，都只给登录的团队成员看。
- **诱饵那一侧的提示里绝对不能出现**这些内容，否则诱饵会「开天眼」。
- 人类接手诱饵时，网页也不显示骗子心智。只有在旁观，或者人类在扮骗子时，才显示。
- 人类扮骗子时，可以看到自己的真人卡和面具。

## 剧本补充（共 12 个，加上给 36 个旧剧本补 `cover`）

| 类型 | 新增 |
|---|---|
| `authority-impersonation` 冒充公检法、税务 | 中 2、英 1（英文：冒充 IRS 或 FBI） |
| `otc-mule` USDT 承兑、跑分招募 | 中 2、英 1 |
| `liquidity-mining` 假挖矿、授权盗币 | 中 2、英 1（给的是「矿池合约地址」，正好测 D33 的合约警告） |
| 英文补齐 | `exchange-impersonation`、`family-emergency`、`fake-loan` 各 1 |

- 每个新剧本都要写 `cover`。
- 每类至少 1 个带 `poison`。
- 参考公开报道写，`source` 里写出处，比如 FBI IC3、公安部反诈中心通报、Sophos 等安全公司报告。
- 地址都是虚构的，但格式要合法。台词要像真实的聊天。
