# BaitNet 演示视频脚本

> 用途：比赛提交用的 demo 视频，也用作 X 帖附件｜目标时长 **2 分 40 秒**（上限 3 分钟）
> 顺序按 [01_功能模块.md](../01_功能模块.md) §1 的 demo 剧本 ①–⑥，再加竞技场和训练台
> 录制环境：`pnpm demo` 跑完后打开 http://localhost:5173，界面切到 **EN**（评委是国际评委）；浏览器缩放 110%，1920×1080
> 旁白用英文，中文对照只给 Dylan 核对意思，不进视频。字幕用英文
> 所有画面里的人名、地址、网址都是虚构的；不要录到 `.env`、终端里的 key 或真实账户

## 录制提示

- **镜头 1 的数字**来自 FBI IC3 2024 年报（$9.3B 是"涉及加密货币的投诉"报告损失），字幕里写明来源，不要改成"全球"。
- 镜头 3、4 的对话可以先在规则模式下录，画面稳定；如果 11/13 前配好了大模型 key，镜头 4 改用大模型模式，注入攻击更有说服力。
- 镜头 5 的投毒剧本推荐 `exchange-impersonation-04`（中文，劝举报）。如果录英文界面不想出现中文对话，改用 `exchange-impersonation-03`。
- 镜头 7 是 06 赛道的硬要求，**不能剪短**；务必让 `pnpm demo` 日志里 `唯一的 key 是 function-call key（receiver=vault.test.near, methods=[pay], allowance=1 NEAR）` 这一行出现在画面里至少 2 秒（日志是中文，配英文字幕 "agent's only key: function-call key → vault.pay, 1 NEAR allowance"）。
- 镜头 9、11 必须保留 "sample data" / "recorded sample" 标签，不要遮掉，避免夸大。
- 不要录到：`.env`、`~/.near-credentials`、终端里的任何 key、浏览器书签栏。
- 导出：1080p、H.264、带英文字幕的 mp4，X 普通账户的视频上限是 2 分 20 秒，X 帖用另剪的 2:20 版本（删去镜头 9 和 11）。
