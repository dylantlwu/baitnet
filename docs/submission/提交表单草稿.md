## Project description（1983 字符）

复制下面代码块里的全部内容（不含开头和结尾两行围栏）：

```text
BaitNet uses AI decoys to get payment addresses from scammers, and makes AI agents and NEAR Intents market makers refuse to pay them.

Problem: crypto fraud caused $9.3B of reported losses in 2024 (FBI IC3). Scam addresses are usually known only after victims pay, and bridges, wallets, intent solvers and AI agents have no shared check before paying.

How it works:
1. A scammer AI (34 original scripts) talks to a decoy AI playing a victim; a human can take over either side or whisper hints.
2. Addresses (NEAR, EVM, Tron, BTC) are extracted live. Known exchange, bridge and token addresses are filtered as poison, and a human approves every alert.
3. Approved alerts go to an AlertRegistry contract on NEAR: address, chain, level, status and an evidence hash. No personal data on chain.
4. A guard (5 signals) returns allow/warn/block. The agent wallet refuses to sign on block, asks a human on warn. A simulated Intents market maker refuses to quote for flagged recipients.

NEAR specifics: the payment agent's only key is a function-call key for vault.pay (it cannot transfer NEAR or add keys). The Vault contract calls registry.check cross-contract before every transfer and fails closed. Demo: a prompt-injected agent tries to pay a flagged account, the guard blocks it, and a direct vault.pay fails on chain.

Privacy (track 03): the main flow keeps encrypted evidence. A zero-retention mode sends redacted chat logs to a TEE model on NEAR AI Cloud, writes nothing on our server (tested) and returns a fresh-nonce attestation check. Not yet tested against live NEAR AI Cloud (no key); offline it uses a recorded attestation.

Experts rate and rewrite decoy replies; approved rewrites join a playbook and become regression tests.

Runs with no keys: pnpm install && pnpm demo (local NEAR sandbox, replayed LLM). Rules-mode eval: 34/34, which only proves the pipeline works; LLM-mode scores need a key. Most code was generated by Claude Code agents and reviewed by the author.
```
