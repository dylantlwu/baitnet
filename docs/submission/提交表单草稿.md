## Project description（1959 字符）

复制下面代码块里的全部内容（不含开头和结尾两行围栏）：

```text
BaitNet uses AI decoys to get payment addresses from scammers, and makes AI agents and NEAR Intents market makers refuse to pay them.

Problem: crypto fraud caused $9.3B of reported losses in 2024 (FBI IC3). Scam addresses are usually known only after victims pay, and wallets, intent solvers and AI agents have no shared check before paying.

How it works:
1. A scammer AI (48 fictional scripts) talks to a decoy AI playing a victim; a human can take over either side or whisper hints.
2. The decoy plays a concrete persona card, thinks before each reply, and code checks it for AI tells and contradictions. The scammer has a mask, an operator card and a suspicion score: it tests, sends fake addresses or vanishes.
3. Addresses (NEAR, EVM, Tron, BTC) are extracted live. Exchange, bridge and token addresses are blocked; doubtful ones (sent after "are you a bot?", network mismatch, contracts, very old accounts) get warnings a human must clear. A human approves every alert.
4. Approved alerts go to an AlertRegistry contract on NEAR testnet: address, chain, level, status, evidence hash. No personal data on chain.
5. A guard returns allow/warn/block: the agent wallet refuses to sign on block, asks a human on warn; a simulated Intents market maker refuses to quote.

NEAR specifics: the payment agent's only key is a function-call key for vault.pay. The Vault calls registry.check cross-contract and fails closed, so a prompt-injected agent paying a flagged account fails on chain.

Privacy (track 03): LLMs run on NEAR AI Cloud TEE models; live attestation passes 18/18 checks with a fresh nonce. A zero-retention mode writes nothing on our server (tested).

Live eval (DeepSeek V4.1 Flash, 48 scripts, suspicious scammers): 42 addresses, 0 leaks, 1 hijack, 13/13 poison filtered.

Runs with no keys: pnpm install && pnpm demo (local NEAR sandbox). Most code was written by Claude Code; the author made the product decisions and did acceptance testing.
```
